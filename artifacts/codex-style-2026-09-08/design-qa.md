## 迭代记录

1. 初始实现的任务入口受父 grid 的内容宽度限制，按钮组过窄。改为 flex 布局，并按内容宽度在四列/两列间切换。`empty-final.png` 已验证。
2. macOS 合并标题栏后，窄窗口“更多”按钮的点击受到窗口拖动区域影响。为整个菜单容器及弹出区域显式设置 no-drag。原生 E2E 先发现失败，修复后定向测试及最终完整测试均通过。
3. 旧样式在窄桌面窗口中把右侧面板覆盖在对话上。新主题在宽度大于 720px 时保留并排布局，并在 980px 以下收窄工具面板。900px 检查中主内容右边界 620px，所有输入控件右边界不超过 595px；工具栏高 46px。`narrow-final.png` 已验证。

## 五项检查

- 字体与排版：使用现有系统中文字体栈。导航 13px、辅助文字 11–12px、正文跟随用户字号，空状态标题 24px；长标题和文件名保留截断。参考低分辨率且密度未知，因此不宣称字体逐像素一致。
- 间距与布局：对话最大宽度 940px，正文与输入框对齐；侧栏 238px；顶部 56px；输入框圆角 21px；取消按钮按下时的缩放；右侧六个工具改为紧凑横排图标入口。
- 颜色：保留 Rux 浅色方向；暖灰侧栏、白色内容面、浅灰用户消息，弱化分隔线和阴影。权限风险、错误、Git 增删行保留各自语义颜色。
- 图像与资产：保留 Rux 标识和既有 Phosphor 图标。没有复制 Codex 品牌图标，也没有新增装饰插画。参考图清晰度有限，仅用于风格与结构观察。
- 文案与内容：新会话提供四个可编辑的任务起点。点击只填入草稿并聚焦，不直接发起任务。所有原有 Agent、模型、权限、图片、Git、终端入口继续可用。

- `pnpm package`：成功生成 macOS arm64 本地桌面包；仍未签名。

没有剩余的 P0/P1/P2 实现问题。参考无法覆盖最新版 Codex 全部界面，深色主题和逐像素匹配不属于此次适配验收范围。原生 E2E 的 Agent 输出使用现有测试模式，不代表真实模型账号调用测试。
