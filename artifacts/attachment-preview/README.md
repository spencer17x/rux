# 图片附件预览修复

原问题：草稿和已发送消息的附件区只显示文件名，没有图片预览组件或图片读取 IPC；原 CSP 也未允许图片 data URL。

实现：

- `AttachmentList` 在草稿和历史消息中共用，图片显示缩略图，点击后通过统一 Modal 查看完整图片；关闭 / Escape 返回附件按钮。
- 附件删除按钮独立于预览按钮；普通文件继续显示文件名。
- 图片靠近可视区域时才加载，离开后释放图片数据；主进程只返回经过路径、格式头、普通文件类型和 10 MB 大小检查的 PNG / JPEG / GIF / WebP 数据。
- CSP 仅增加 `img-src 'self' data:`，没有开放 file URL、远程图片或 Renderer Node 访问。
- 图片文件不存在、无法读取或无法解码时显示错误与重试入口。
- 浏览器开发预览也支持选择本地图片、粘贴和拖放，预览数据仅存在该页面会话内。

验证：111 项单元测试通过，14 项原生 Electron E2E 通过，UI 组件边界检查和类型检查通过，桌面包生成成功。原生 E2E 检查实际图像解码尺寸，覆盖选择 / 粘贴 / 拖放、发送前后预览、关闭后的焦点、SQLite 持久化后的重启查看以及外部文件丢失。

截图（1280 × 720，浏览器开发预览，测试图片为项目内的已选设计稿）：

- `thumbnail.jpg`：发送前缩略图。
- `enlarged.jpg`：点击后的完整图片预览。

浏览器控制台没有 error / warn。没有发起真实 Agent 图片请求。
