# 模式菜单留白修复

用户截图见 `before.png`；实际修复效果见 `after.jpg`（1280 × 720，默认模式选中）。

原因：外层浮层固定 254px，内部模式列表单独固定 190px，导致右侧多出 64px 留白。

修复：增加共享 `xs` 浮层规格（160px），用于短模式选项；内部列表统一铺满外层，模式列表内边距从 8px 收到 6px。同类模型、权限、Agent 浮层继续由其外层规格控制宽度。

浏览器实测：外层 160px、内部列表 158px（扣除边框）、选项 146px、左右留白均为 6px。已操作计划 → 默认并确认勾选与工具栏文字同步。

验证：UI 边界检查、类型检查、桌面构建与打包通过；原生窄窗口菜单和模型滑杆相关 E2E 两项通过。
