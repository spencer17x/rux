# Composer completion verification

Implemented September 13, 2026:

- Explicit Codex default/plan and disabled/live search settings, verified against the protocol generated by the pinned Codex 0.154.0 executable.
- Model input capabilities propagated from agent catalogs / configured providers and enforced on both sides of IPC. Text-only models cannot send attached images; attachments stay in the draft.
- Responses-compatible API history, plan/default instructions, persisted API conversation mode, text/image/PDF/Office inputs with capability settings and visible attachment errors. Native and API conversation bindings remain distinct.
- macOS system speech helper bundled in the desktop app. Speech and microphone authorization precede recording; WAV capture, 60-second limit, cancel, draft append, conversation-switch cleanup, temporary audio deletion, and permission errors are implemented. On-device recognition is preferred when supported.

Automated validation:

- 123 unit tests passed; type check, UI boundary check, web/desktop builds and macOS packaging passed.
- Full Electron suite: 17 passed. The three new feature tests were also rerun after subsequent refinements.
- Voice E2E uses Chromium's synthetic microphone device and a controlled transcriber response; it checks actual AudioWorklet → WAV → IPC flow, append/cancel and send-button state. It does not record the user's microphone.
- Custom API E2E sends real HTTP requests to a local fixture server, verifying request history, plan/default instructions, and context after app restart.
- The packaged native helper reports `available: true`, `onDevice: true`, `permission: not-determined` on this Mac. The package includes microphone / speech usage descriptions and entitlements.

Real Apple transcription acceptance remains pending first OS authorization. `verify-system-voice.mjs` uses a locally synthesized Chinese audio file and the packaged app; run it from the repository root only when ready to answer the macOS authorization prompt. It never opens the microphone. This is separate from automated fixture coverage.
