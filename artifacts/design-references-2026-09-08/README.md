# Rux 界面设计参考

这些是从官方产品页面取得并检查的实际参考素材，不是 Rux 的实现截图。

- Linear，2026-03-12：[A calmer interface for a product in motion](https://linear.app/now/behind-the-latest-design-refresh)。参考侧栏的弱化层级、较小图标、稳定对齐与紧凑导航。`linear-sidebar.png` 是页面中放大的官方对比图截图。
- Raycast，2026-05-14：[The New Raycast](https://www.raycast.com/blog/the-new-raycast)。`raycast-ai.png` 是官方聊天界面配图，参考聊天侧栏、输入区、低干扰操作的组织，不引入其记忆或插件功能。
- Zed，2026-04-22：[Introducing Parallel Agents in Zed](https://zed.dev/blog/parallel-agents)。`zed-conversation.webp` 与 `zed-workspace.webp` 是官方界面图，参考项目会话分组及按需并排的工作区。不引入代码编辑器、跨仓库权限或额外的 Agent 能力。

Rux 的调整目标：去掉大标题和重复卡片，让对话成为主要内容；统一 13–15px 的界面文字层级、紧凑行高和细分隔线；将右侧六个大菜单缩为按需工具入口；只保留现有可执行功能。
